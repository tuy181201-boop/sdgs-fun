MCA2RAW Protocol

High-Performance Terrain Generation & Extraction Pipeline for SDGS (System Distributed Game Server)

MCA2RAW — это автономный программный комплекс и спецификация формата данных, предназначенные для конвертации ландшафта из Minecraft (в формате .mca) в сырые бинарные массивы высот (.raw), оптимизированные для чтения игровым движком SDGS на C++.

🚀 Ключевые возможности

  • Zero-Touch генерация: Python-оркестратор сам запускает headless-сервер, управляет Chunky через RCON и выключает сервер.
  • Мультиязычный пайплайн: Java (быстрый парсинг NBT), Python (оркестрация, Web GUI), BAT (TUI).
  • Двойной интерфейс: GUI на pywebview и TUI на чистом .bat.
  • Прямая конвертация: Данные сохраняются в формате t.x.z.raw, который читается в C++ за миллисекунды.

🏗️ Архитектура

[ Minecraft Server (Paper) ] 
       │ (RCON)
       ▼
[ Python Orchestrator (app.py) ] ──> [ Web GUI (pywebview) ]
       │                          └──> [ TUI (BAT) ]
       │ (subprocess)
       ▼
[ Java Extractor (McExtractor.jar) ]
       │ (Binary parsing)
       ▼
[ Output: t.x.z.raw ] ──> [ C++ SDGS Engine ]

📜 Спецификация формата .raw

Протокол MCA2RAW сохраняет карту высот (Heightmap) одного региона Minecraft (512x512 блоков) в бинарный файл формата .raw.

Правила именования

Файлы сохраняются в папку с именем сида мира (seed/) и имеют строгую структуру:

  • t.x.z.raw — где x и z — координаты региона (например, t.-1.0.raw).

Структура файла

ПараметрЗначение
Размер файлаРовно 524,288 байт
Формат данныхsigned 16-bit integer (Little-Endian, short в Java, int16_t в C++)
Порядок байтовПострочно (Row-major). Сначала 512 значений по X для Z=0, затем для Z=1 и т.д.
Индексindex = (Z * 512) + X
ПустотыЕсли нет твердых блоков, записывается значение -64

Пример чтения в C++ (SDGS)

#include <fstream>
#include <vector>

const int REGION_SIZE = 512;
const int TOTAL_BLOCKS = REGION_SIZE * REGION_SIZE;

std::vector<int16_t> LoadRawTerrain(const std::string& filepath) {
    std::ifstream file(filepath, std::ios::binary);
    std::vector<int16_t> heights(TOTAL_BLOCKS);
    // Чтение всего массива за один проход
    file.read(reinterpret_cast<char*>(heights.data()), TOTAL_BLOCKS * sizeof(int16_t));
    return heights;
}

⚙️ Требования и файлы

Для работы MCA2RAW требуются следующие компоненты. Тяжелые файлы не хранятся в Git, поэтому скачайте их вручную:

☕ JDK 21 (Temurin) Распакуйте в MCAGenerator/jdk-21 📄 Paper 1.21.11 Переименуйте в server.jar 🌍 Chunky Plugin Положите в plugins/
  • ОС: Windows 10/11 (x86-64).
  • Python: Версия 3.11+ (с pywebview и mcrcon).
  • Компилятор C: GCC или Clang (для сборки key.exe).

🛠️ Установка и настройка

1. Установка зависимостей Python

pip install -r requirements.txt

2. Настройка RCON

В файле MCAGenerator/server.properties должны быть строки:

enable-rcon=true
rcon.password=mcautogen
rcon.port=25575

3. Компиляция Java-парсера

cd libs
javac -cp "NBT-6.1.jar" McExtractor.java
jar cfe McExtractor.jar McExtractor *.class

🎮 Использование

Режим 1: Web GUI

python app/mca2raw_gui.py

Режим 2: TUI (Консольный интерфейс)

Запустите run.bat в Windows. Вас встретит меню с управлением стрелками ↑/↓. Выберите "Генерация мира (Zero-Touch)", и скрипт сам запустит сервер, сгенерирует регионы и конвертирует их в RAW.
