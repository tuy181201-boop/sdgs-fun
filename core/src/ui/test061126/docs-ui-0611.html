Гибридная архитектура UI: Lisp (Raylib) + Python (HTML/PNG)

Архитектура "State-Driven UI"

Данная подсистема реализует паттерн Offscreen UI Rendering (рендеринг интерфейса вне основного игрового окна). Это позволяет полностью изолировать сложный дизайн (HTML/CSS/JS) от игрового цикла.

Как это работает:

  1. Python (Рендерер): Генерирует интерфейс (через Pillow или Playwright) и сохраняет его как ui.png.
  2. Lisp (Игровой движок): Raylib открывает окно, рисует игру, а затем накладывает поверх ui.png.
  3. BAT (Оркестратор): Запускает Python в фоне и Lisp в среде MSYS2.
  4. Взаимодействие: При клике по кнопке, Lisp создаёт файл click.txt. Python читает его, меняет картинку и сохраняет. Lisp мгновенно подхватывает обновлённый ui.png.
Почему это круто? Если Python-скрипт упадёт или зависнет, игра продолжит работать с последней загруженной картинкой. Вы можете менять дизайн интерфейса, не перекомпилируя игровой движок.

Настройка окружения (MSYS2)

Для работы системы требуется установленный MSYS2 с компилятором и SBCL.

1. Установка пакетов

Откройте терминал MSYS2 UCRT64 и выполните:

pacman -S mingw-w64-ucrt-x86_64-sbcl mingw-w64-ucrt-x86_64-python mingw-w64-ucrt-x86_64-pkgconf

2. Установка Quicklisp (Сетевой патч)

Из-за блокировки сокетов в Windows, стандартная установка Quicklisp может не сработать. Мы используем PowerShell для скачивания архивов.

Файл C:/msys64/home/Tuy181201/.sbclrc должен содержать патч:

;; 6. ПАТЧ: Скачивание через PowerShell
(in-package #:ql-http)
(defun fetch (url file &rest rest)
  (declare (ignore rest))
  (let* ((url-string (if (stringp url) url (urlstring url)))
         (https-string (if (search "http://" url-string)
                           (concatenate 'string "https://" (subseq url-string 7))
                           url-string))
         (file-path (merge-pathnames file))
         (file-string (namestring file-path)))
    (ensure-directories-exist file-path)
    (format t "~&; [POWERSHELL] Скачиваем ~A~%" https-string)
    (let ((cmd (format nil "$ProgressPreference = 'SilentlyContinue'; Invoke-WebRequest -Uri '~A' -OutFile '~A'" https-string file-string)))
      (sb-ext:run-program "powershell.exe"
                          (list "-NoProfile" "-Command" cmd)
                          :search t
                          :output *standard-output*
                          :error *error-output*))
    (if (probe-file file-path)
        (progn
          (format t "~&; [POWERSHELL] Успешно скачано!~%")
          (probe-file file-path))
        (error "PowerShell не смог скачать файл ~A" url-string))))

Исходный код компонентов

1. Python: make_ui.py

Генерирует картинку и слушает файл-сигнал.

import time, os
from PIL import Image, ImageDraw

UI_PATH = "C:/Users/Tuy181201/sdgs-fun/core/src/ui/assets/ui.png"
CLICK_PATH = "C:/Users/Tuy181201/sdgs-fun/core/src/ui/assets/click.txt"

def draw_ui(state):
    img = Image.new('RGBA', (800, 600), color=(40, 44, 52, 255))
    draw = ImageDraw.Draw(img)
    if state == 0:
        btn_color, text = (0, 120, 215, 255), "Real HTML Button!"
    else:
        btn_color, text = (40, 167, 69, 255), "Clicked!"
    
    draw.rectangle([300, 250, 500, 300], fill=btn_color)
    draw.text((340, 265), text, fill=(255, 255, 255, 255))
    
    temp_path = UI_PATH + ".tmp.png"
    img.save(temp_path, format="PNG")
    if os.path.exists(UI_PATH): os.remove(UI_PATH)
    os.rename(temp_path, UI_PATH)

state = 0
draw_ui(state)
print("[Python] Generator started. Waiting for clicks...")

while True:
    if os.path.exists(CLICK_PATH):
        os.remove(CLICK_PATH)
        state = 1
        draw_ui(state)
        time.sleep(0.5)
        state = 0
        draw_ui(state)
    time.sleep(0.1)

2. Lisp: ui_renderer.lisp

Отображает ui.png поверх игры и обрабатывает клики (защита от дребезга через mouse-was-down).

(load "C:/msys64/home/Tuy181201/.sbclrc")
(ql:quickload "cl-raylib" :silent t)

(cl-raylib:init-window 800 600 "Lisp + Interactive HTML UI")

(let ((ui-texture nil)
      (last-write-time 0)
      (ui-path "C:/Users/Tuy181201/sdgs-fun/core/src/ui/assets/ui.png")
      (click-path "C:/Users/Tuy181201/sdgs-fun/core/src/ui/assets/click.txt")
      (mouse-was-down nil))

  (loop while (not (cl-raylib:window-should-close))
        do 
           (when (probe-file ui-path)
             (let ((current-write-time (ignore-errors (file-write-date ui-path))))
               (when (and current-write-time (or (null ui-texture) (> current-write-time last-write-time)))
                 (when (probe-file ui-path)
                   (let ((new-tex (ignore-errors (cl-raylib:load-texture ui-path))))
                     (when new-tex
                       (when ui-texture (ignore-errors (cl-raylib:unload-texture ui-texture)))
                       (setf ui-texture new-tex)
                       (setf last-write-time current-write-time)))))))

           (let ((mouse-is-down (cl-raylib:is-mouse-button-pressed 0)))
             (when (and mouse-is-down (not mouse-was-down))
               (let ((mx (cl-raylib:get-mouse-x)) (my (cl-raylib:get-mouse-y)))
                 (when (and (> mx 300) (< mx 500) (> my 250) (< my 300))
                   (ignore-errors
                     (with-open-file (s click-path :direction :output :if-exists :supersede)
                       (format s "clicked"))))))
             (setf mouse-was-down mouse-is-down))

           (cl-raylib:begin-drawing)
           (cl-raylib:clear-background (cl-raylib:make-rgba 30 30 30 255))
           (cl-raylib:draw-circle 400 300 50.0 (cl-raylib:make-rgba 255 0 0 255)) 
           (when ui-texture (cl-raylib:draw-texture ui-texture 0 0 (cl-raylib:make-rgba 255 255 255 255)))
           (cl-raylib:end-drawing))

  (when ui-texture (ignore-errors (cl-raylib:unload-texture ui-texture))))
(cl-raylib:close-window)

3. BAT: launch.bat

Оркестратор. Восстанавливает PATH, запускает Python и Lisp.

@echo off
set PATH=C:\Windows\System32;C:\Windows;%PATH%

echo [STEP 1] Starting Python UI Generator...
start "Python UI" cmd /k "cd /d C:\Users\Tuy181201\sdgs-fun\core\src\ui\python && python make_ui.py"

timeout /t 2 /nobreak >nul

echo [STEP 2] Starting Lisp Engine...
"C:\msys64\usr\bin\bash.exe" -lc "cd /c/Users/Tuy181201/sdgs-fun/core/src/ui/lisp && /c/msys64/ucrt64/bin/sbcl.exe --script ui_renderer.lisp"

taskkill /F /IM python.exe >nul 2>&1

Сборка Python в EXE (Опционально)

Чтобы пользователю не нужно было устанавливать Python, можно скомпилировать скрипт в исполняемый файл .exe с помощью PyInstaller.

1. Установка PyInstaller

pip install pyinstaller

2. Сборка

Выполните в папке с вашим make_ui.py:

pyinstaller --onefile --noconsole make_ui.py
  • --onefile — собирает всё в один EXE.
  • --noconsole — скрывает чёрное окно консоли Python.

Готовый файл будет лежать в папке dist/. В BAT-файле замените вызов python make_ui.py на start "" "make_ui.exe".

Важно: Если вы используете Pillow, PyInstaller может потребовать указать путь к DLL. В таком случае используйте флаг --add-data "venv/Lib/site-packages/PIL;PIL". Если вы перейдёте на Playwright, сборка в EXE сильно усложнится, так как потребуется упаковать браузер Chromium.
