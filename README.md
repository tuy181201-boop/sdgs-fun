## 📖 О проекте

**SDGS** (System Distributed Game Server) — это платформа для создания **автономных, детерминированных и живых игровых миров**. В отличие от традиционных игр, SDGS не требует интернета, облачных серверов или постоянного питания от сети. Вся вычислительная мощность распределена между кластером микроконтроллеров (ESP32, Arduino) и монолитным ядром для ПК.

Проект основан на принципах:
- **Автономность** — оффлайн для исследования мира, онлайн для PvP, питание от аккумулятора, связь для онлайн через домашний Wi-Fi.
- **Детерминизм** — фиксированная физика 60 Гц, 64-битный LCG, Fixed48_20.
- **Открытость** — все форматы данных документированы.
- **Мультиязычность** — 24 языка программирования.
- **Мультиплатформенность** — ESP32, Win10/11 x86-64, Android, iOS.

**Три значения SDGS:**
1. **Synchronized Deterministic Game System** (инженерное)  
2. **Self‑Discovering Generative Sandbox** (моддерское)  
3. **Stories Dreamed Game Spaces** (игровое)

## 🏗️ Архитектура (в разработке)

### Железная платформа (кластер ESP32 и STM32)

| Чип | Роль | Прошивка | Статус |
|-----|------|----------|--------|
| ESP32‑S3 | Маршрутизатор | router.bin | В разработке |
| ESP32‑P4 #1 | Хранитель Земли (ландшафт) | land.bin | В разработке |
| ESP32‑P4 #2 | Хранитель Жизни (NPC, экосистема) | life.bin | В разработке |
| ESP32‑P4 #3 | Хранитель Разума (AI, физика) | mind.bin | В разработке |
| ESP32‑C5 | Голос Мира (шлюз, связь) | gateway.bin | В разработке |

- **Связь:** SPI (40 МГц, DMA) или UART.
- **Мир:** физика 60–120 Гц, воклельные модели.
- **Хранение:** каждая microSD (exFAT, 64 ГБ) подключена к ESP32-P4 с присвоением роли B - буффер / C - системные файлы игрового движка / L - реализация NPC / M - модельки и ландшафт.

### Монолитное ядро Win10/11 x86-64 (C++17)

Модули:
- **LandModule** — ландшафт (SWT, LOD).
- **LifeModule** — NPC, экономика, медицина.
- **MindModule** — физика, AI (CLIPS, Lisp), скрипты.
- **NetworkModule** — WebSocket, HTTP, REST API.
- **UIModule** — рендеринг (OpenGL/Vulkan), шейдеры.
- **ShaderManager**, **VoxelRenderer**, **LandscapeRenderer**, **FontRenderer**, **EFXRenderer**.
- **BufferManager** — управление кэшем и распаковкой ZIP.
- **ScriptManager** — 22 языка + LLVM IR.
- **PythonBridge** (pybind11) — мост к Python AI Core.
- **DNAParser** — парсинг генома мира.

## 📂 Форматы данных (38 расширений)

| Категория | Расширения | Назначение |
|-----------|------------|------------|
| **Генеративные (Pascal)** | `.vxps`, `.anps`, `.wtps`, `.efxps`, `.fldps`, `.genps` | Скрипты генерации вокселей, анимаций, ландшафта, эффектов, полей |
| **Системные (логика)** | `.krl`, `.ql`, `.dl`, `.lg`, `.mood`, `.lineage`, `.echo`, `.legacy`, `.event`, `.rule`, `.dream`, `.state`, `.mod`, `.proto` | Поведение NPC, квесты, диалоги, эволюционные данные |
| **Бинарные (результат)** | `.vxl`, `.swt`, `.wt`, `.anim`, `.efx`, `.scl`, `.smp` | Воксельные модели, структурированный ландшафт, анимации, эффекты |
| **Мультимедиа** | `.snd`, `.vid`, `.scn`, `.seq`, `.menu` | Аудио, видео, сцены, интерфейсы |
| **Химия/медицина** | `.chem`, `.med`, `.rec`, `.law16` | Системы здоровья, веществ |
| **Реестры** | `.rgs`, `.assoc`, `.meta` | Связь UID → путь, ассоциации, метаданные |
| **Шрифты** | `.vfont`, `.afont` | Воксельные и альтернативные шрифты |
| **Геном мира** | `.dna` | Все параметры мира (физика, климат, NPC, экономика, эволюция, эстетика, камера) |
| **Музыка** | `.ts` (TrackScript) | Нотные описания треков с модуляциями и 8D-эффектом |
| **Изображения** | `.imgps` | Генерация текстур (RGB) |

**Размер вокселя:**  
- Объекты: √10/10 мм ≈ 0.3162277660168379332 мм  
- Ландшафт: 20√10 см ≈ 63.24555320336758664 см  
- LOD-цепочка: LOD0…LOD4
