## 📖 О проекте

**SDGS** (System Distributed Game Server) — это платформа для создания **автономных, детерминированных и живых игровых миров**. В отличие от традиционных игр, SDGS не требует интернета, облачных серверов или постоянного питания от сети. Вся вычислительная мощность распределена между кластером микроконтроллеров (ESP32, STM32) и монолитным ядром для ПК, а роль тяжелого серверного бэкенда выполняет двухпроцессорная система на базе Intel Xeon.

Проект основан на принципах:
- **Автономность** — оффлайн для исследования мира, онлайн для PvP, питание от аккумулятора, связь для онлайн через домашний Wi-Fi.
- **Детерминизм** — фиксированная физика 60 Гц, 64-битный LCG, Fixed48_20.
- **Открытость** — все форматы данных документированы.
- **Мультиязычность** — 24 языка программирования.
- **Мультиплатформенность** — ESP32, STM32, Win10/11 x86-64, Linux (Ubuntu), Android, iOS.

**Три значения SDGS:**
1. **Synchronized Deterministic Game System** (инженерное)  
2. **Self‑Discovering Generative Sandbox** (моддерское)  
3. **Stories Dreamed Game Spaces** (игровое)

## 🏗️ Архитектура (в разработке)

Архитектура SDGS строится на гетерогенной модели, где задачи разделены между серверным ядром (Xeon), клиентским рендерингом и физическим миром микроконтроллеров (Hardware-in-the-Loop).

### 🖥️ 1. Вычислительное ядро: Dual-Socket Xeon + AI

Текущая конфигурация серверной части проекта разворачивается на базе двухпроцессорного сервера Intel Xeon Scalable под управлением **Ubuntu 22.04 LTS**. Это позволяет разделить задачи реального времени и инференс языковых моделей между физически изолированными NUMA-узлами.

| Компонент | Конфигурация | Роль |
|---|---|---|
| **Xeon #1** | 20 ядер / 40 потоков, DDR4-2933 | Управление мехатроникой (кластером MCU), резерв, мост к Xeon #2 |
| **Xeon #2** | 20 ядер / 40 потоков, DDR4-2933 | Локальный инференс LLM (Qwen 3.5 9B / Qwen 3.8 27B) |
| **Межпроцессорная шина** | Intel UPI (Ultra Path Interconnect) | Обмен данными между сокетами |
| **Память** | 6 каналов DDR4-2933 на сокет (до 192 ГБ в сумме) | Разделяемая и локальная память |

#### Распределение ядер (Core Pinning)
Все 40 потоков жестко закреплены за конкретными задачами через `pthread_setaffinity_np` и `isolcpus`, чтобы исключить миграцию и снизить задержки:

*   **Xeon #1:**
    *   `Ядра 0–4`: Мехатроника (STM32MP25x) — обработка байтовых потоков через OpenAMP/RPMsg.
    *   `Ядра 5–9`: Мехатроника (ESP32) — связь по SPI (40 МГц, DMA) или UART.
    *   `Ядра 10–11`: **Мост (Bridge #1)** — асинхронная передача данных на Xeon #2.
    *   `Ядра 12–19`: **Резерв / Симуляция** — SLAM, компьютерное зрение. При зависании основного потока резервное ядро подхватывает задачу.
*   **Xeon #2:**
    *   `Ядра 20–21`: **Мост (Bridge #2)** — прием данных и формирование промптов.
    *   `Ядра 22–39`: **LLM (Qwen)** — инференс моделей в `llama.cpp` с NUMA-оптимизацией (`numactl --cpunodebind=1`).

### 🔌 2. Железная платформа (Кластер ESP32 и STM32)

Кластер микроконтроллеров выступает в роли распределенной сенсорной сети и исполнительных механизмов (Digital Twin физического мира). Связь с сервером Xeon осуществляется по бинарному протоколу `[Header (2B)] [Length (2B)] [Payload] [CRC (2B)]`.

**Состав кластера:**
*   **STM32MP25x (x3):** Гетерогенные чипы (2×Cortex-A35 + Cortex-M33 + Cortex-M0+). Linux на A35 общается с RT-ядром (M33) через OpenAMP. 
*   **ESP32-P4 (xN):** 2×RISC-V HP (до 400 МГц) + 1 LP. Работают под FreeRTOS/ESP-IDF, передают данные на сервер по SPI/UART.

| Чип | Роль | Прошивка | Статус |
|-----|------|----------|--------|
| STM32MP25x #1 | Хранитель Земли (ландшафт) | land.bin | В разработке |
| STM32MP25x #2 | Хранитель Жизни (NPC, экосистема) | life.bin | В разработке |
| STM32MP25x #3 | Хранитель Разума (AI, физика) | mind.bin | В разработке |
| ESP32‑C5 | Связь с сервером (оффлайн/онлайн) + PvP | gateway.bin | В разработке |
| ESP32-P4 | нейроускоритель для Xeon | boost.bin | В разработке |

*   **Хранение:** SSD 2TB c каталогами B/M/L/C

### 💻 3. Монолитное ядро Win10/11 x86-64 (C++17)

Клиентская часть и редакторы работают на ПК. Модули:
- **LandModule** — ландшафт (SWT, LOD). Протокол MCA2RAW (Python 3.11 + Java JDK 21 + C++ 20)
- **LifeModule** — NPC, экономика, медицина. Протокол GPT2NPC (Python 3.11 + Lisp (SBCL + ECL + CLIPS) + C++ 20)
- **MindModule** — физика, AI, скрипты.
- **NetworkModule** — WebSocket, HTTP/HTTPS, REST API (связь с Xeon-сервером).
- **UIModule** — рендеринг (OpenGL/Vulkan), шейдеры.
- **ShaderManager**, **VoxelRenderer**, **LandscapeRenderer**, **FontRenderer**, **EFXRenderer**.
- **BufferManager** — управление кэшем и распаковкой ZIP.
- **ScriptManager** — 22 языка + BAT/BASH.
- **PythonBridge** (pybind11) — мост к Python AI Core.
- **DNAParser** — парсинг генома мира. (Pascal + Lisp (SBCL + ECL + CLIPS) + C++ 20)

## 📂 Форматы данных (38 расширений)

| Категория | Расширения | Назначение |
|-----------|------------|------------|
| **Генеративные (Pascal)** | `.vxps`, `.anps`, `.wtps`, `.efxps`, `.fldps`, `.genps` | Скрипты генерации вокселей, анимаций, ландшафта, эффектов, полей |
| **Системные (логика)** | `.krl`, `.ql`, `.dl`, `.lg`, `.mood`, `.lineage`, `.echo`, `.legacy`, `.event`, `.rule`, `.dream`, `.state`, `.mod`, `.proto` | Поведение NPC, квесты, диалоги, эволюционные данные |
| **Бинарные (результат)** | `.vxl`, `.swt`, `.wt`, `.anim`, `.efx`, `.scl`, `.smp` | Воксельные модели, структурированный ландшафт, анимации, эффекты |
| **Мультимедиа** | `.snd`, `.vid`, `.scn`, `.seq`, `.menu` | Аудио, видео, сцены, интерфейсы |
| **Химия/медицина** | `.chem`, `.med`, `.rec`, `.law16` | Системы здоровья, веществ |
| **Реестры** | `.rgs`, `.assoc`, `.meta` | Связь UID → путь, ассоциации, метаданные |
| **Шрифты** | `.vfont`, `.afont` | Воксельные и альтернативные шрифты |
| **Геном мира** | `.dna` | Все параметры мира (физика, климат, NPC, экономика, эволюция, эстетика, камера) |
| **Музыка** | `.ts` (TrackScript) | Нотные описания треков с модуляциями и 8D-эффектом |
| **Изображения** | `.imgps` | Генерация текстур (RGB) |

**Размер вокселя:**  
- Объекты: √10/10 мм ≈ 0.3162277660168379332 мм  
- Ландшафт: 20√10 см ≈ 63.24555320336758664 см  
- LOD-цепочка: LOD0…LOD4
